# The dev team's review, built (Oct 15)

The dev team compared Fovea 1.0's design with the app they ship today, row by row, in the workbook
"Fovea 全应用 UI 新旧图文对照与替换评审 · 2026-10-11" (18 modules, about 250 rows). Each row says what our
design lacks next to theirs. Ryan read it as: *the design missed cases and features*. So every
missing case was built here, in Fovea's own design. Their pictures of their own UI were not used
as a reference. Where the workbook asked for something we had decided against, Ryan decided again
(below). Each change carries the workbook's ID, so the two can be read side by side.

## Seeing the changes

- **Review menu.** It appears with `--review`. It lists every state the
  review added that normal use wouldn't show on demand: a failed sign-in, an ended trial, a chat
  that's no longer available, a dropped connection. They're grouped as a walk through the app
  goes: First Run, Home, Settings, Notch, Menu Bar & System.
- In code, each change is commented `// Oct 15 review, <ID>: …`. FoveaKit/Review.swift holds the
  registry. (Orange tags on each change were drawn for the first walk through and removed on
  Oct 17, at Ryan's word: "don't have any of those marks again.")

```bash
cd FoveaV1 && scripts/bundle.sh && open -n build/Fovea.app --args --reset-onboarding --review
```

## Decided with Ryan

| Question | Decision |
|---|---|
| Their 8-page sidebar (Home, History, Memory, Dictionary, Account, Settings, About, Getting Started) | No sidebar on Home. "We already have all of these in the settings tab." Settings was reorganised to hold them: Getting Started, Dictionary and About became sections of their own, and the menus reach them (Go, Help, Fovea › About). |
| Memory | All of it: browse, search, detail, hide, delete, restore, the access log, agents reading memory (MCP), the first-run disclosure and the reminder. This departs from AGENTS.md's "no UI for curating stored facts": a public app that remembers things lets people see and delete them. |
| Shortcuts | Changeable: record, clear, reset, clash warnings. External keyboards often have no fn key. |
| Recordings | "Recordings are only saved for failed cases, and then it will automatically try to re-transcribe. No audio will be seen by the users." No Play, no Save Audio. A failed transcription retries by itself. |
| Closing a working chat | Closing never stops. Stop is the only way to stop an agent. |
| Streaming answers | No. One line of what the agent is doing, then the whole answer when it's done, as decided. |
| The referent stack's count | "+N" on the stack once more than three are taken. Expanded: one row, swiped left and right when it doesn't fit, each referent numbered in the order taken. A click opens the full view. |
| Paste feedback | Only: hovering the held words keeps them open, and Paste joins Copy. No target app while thinking, no "Pasted" confirmation. |
| Usage stats on Home | None. Home stays a ledger. |
| Text modes | One switch, Tidy my words (on by default). Off pastes exactly what was said. |
| Eye tracking | The controls are designed, but they appear only after the gaze data has been collected. |
| Input Monitoring | A third permission row. Their key engine needs it; 1.0's doesn't, so the first run asks but never waits on it. |
| Which display | Where you're working: each press opens on the display with the pointer (a top-centre island where there's no notch) and stays there until it's done. |
| Back in the first run | On the reading pages, beside the progress line, and ⌘[. Never inside a practice task. |
| Left out, on purpose | The Classic floating window (the notch is Fovea), tutorial videos (the tour can be replayed from Getting Started), their debug settings page and its spatial-annotation switch (the dev team's own tools), and Minimal / Balanced / Full context (ours picks what's sent item by item). |
| Our additions the workbook questioned | Kept, all of them: the name step, Clear my screen, the practice tasks, dictionary import, the eye-tracking request, the calendar, the control board and pulled-out chats, Choose chat before sending. Why each is there is under "Kept" below. |

### Not built, with the reason

- **Usage stats on Home (MW-05.2), streaming answers (DSP-20, QA17/18), a target app or "Pasted" confirmation in the dictation bar (VF06/07/08):** Ryan kept the decided design.
- **Classic floating window (ST-02.2, NH-05), tutorial videos (OB-05), the debug settings page and spatial annotation (ST-09, ST-04.4), Minimal/Balanced/Full context (ST-05.4):** left out on purpose (above).
- **A star or pin on captures (HI-01.4):** the dev team's own app doesn't keep one (their N09); not a missing case.
- **Prompt Builder, the Chrome extension (N13):** retired in the dev team's app.

## Kept, and why (for the dev team)

- **The name step (FR-01/02).** Fovea uses the name: Home's tour link, the board's greeting, the first run's own lines. It's asked before sign-in so the first screen is about the person, not an account.
- **Clear my screen (N04).** Offered, never forced. The practice files need a desktop they can be found on; everything comes back at the end, on Exit tour and on quit.
- **The practice tasks (N05).** Two real requests sent to a real agent, so the first thing you see the agent do is something you asked for. The practice agent answers when no agent is installed.
- **Dictionary import (N06, FR-30).** People arrive from Wispr Flow, Typeless and others with years of words. Bringing them in on day one is the difference between Fovea mishearing your names and not.
- **The eye-tracking request (N07).** A Beta waitlist, honest about being one. The controls only appear once the gaze data exists.
- **The calendar (N08).** Cards for the last three days; everything older lives in the calendar, so nothing disappears and nothing has to be scrolled through.
- **The control board and pulled-out chats (N10).** Several agents at work at once need one place to see them. Closing a chat never stops it (above).
- **Choose chat before sending (N11).** The words and what was taken are seen before they go, and the chat can be changed; Settings › Notch can skip it.
